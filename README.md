# ARKEN Studio — Architecture & Design Website

A modern, responsive, and interactive website concept for an architecture and interior design studio. 
This project focuses on premium UI/UX design, smooth animations, and a refined visual identity using only HTML, CSS, and JavaScript.

---

## Live Preview

https://github.com/Preciey/Arken-Project

---

## About the Project

ARKEN Studio is a fictional architecture and interior design firm website created to demonstrate advanced frontend development skills and modern design principles.

The goal of this project was to build a visually refined, interactive, and fully responsive landing page that reflects a high-end architectural brand.

Key design principles used:
- Minimalist and elegant visual language
- Strong typography hierarchy
- Grid-based layout structure
- Smooth scroll-based animations
- High attention to spacing, alignment, and proportion

---

## Built With

- HTML5
- CSS3 (Custom Properties / Variables)
- Vanilla JavaScript (ES6)
- Intersection Observer API
- CSS Grid
- Flexbox
- Google Fonts (Cormorant Garamond, DM Sans)

---

## Features

- Fully responsive design for mobile, tablet, and desktop
- Custom design system using CSS variables
- Custom animated cursor interaction
- Sticky navigation with scroll-based state changes
- Smooth scroll reveal animations using Intersection Observer
- Fullscreen mobile navigation menu
- Interactive project portfolio grid with hover effects
- Auto-playing testimonials slider with manual controls
- Contact form with basic validation and success feedback
- High-quality micro-interactions and transitions
- Performance-conscious animations

## Getting Started

To run this project locally:

### 1. Clone the repository
```bash
git clone https://github.com/Preciey/Arken-Project
````

### 2. Navigate to the project folder

```bash
cd arken-studio
```

### 3. Open the project

Simply open `index.html` in your browser.
